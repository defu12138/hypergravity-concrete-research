# 组会记录区

本目录用于在 GitHub 上持续记录每次组会的汇报内容、讨论结论、待核对问题和下一步任务。建议只保存结构化 Markdown 记录，不直接提交 PPT、PDF、Word、CAJ、压缩包或老师资料原件。

## 使用方式

1. 每次组会后复制 `template.md`，命名为 `YYYY-MM-DD_topic.md`。
2. 填写 PPT/汇报源、核心结论、老师反馈、待核对项和下一步行动。
3. 如果形成新的研究判断，同步更新 `current_research_summary.md` 和 `handoff/RESEARCH_DECISIONS.md`。
4. 如果只是普通进度记录，不强行改动既有研究结论。
5. 不把本地原始文献、老师资料或大体积演示文件复制进仓库；如确需保留附件，先确认是否适合公开到 GitHub。
